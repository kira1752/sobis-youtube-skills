# Indeks Tema Hallmark (salinan di repo ini)

Folder ini memuat berkas token tema Hallmark yang disalin utuh dari skill Hallmark (lisensi MIT) supaya repo ini berdiri sendiri — agen tidak perlu clone atau berkas dari mesin mana pun di luar repo ini. Yang disalin adalah berkas token `.md` (teks); gambar pratinjau tema tidak disertakan.

- Satu tema dipakai per video, dikunci sebelum kemasan dimulai (lihat `../../SKILL.md` bagian tema dan `PIPELINE.md` di akar repo).
- Ambil blok token `:root` dari berkas tema terpilih; jangan mencampur token dua tema.
- Tema yang sudah teruji penulis repo ini: `blueprint.md`. Tema lain sah dipakai, tetapi perlakukan sebagai belum teruji di pipamu: jalankan lint Impeccable dan periksa mata seperti biasa.
- Font yang dinamai tema mungkin tidak terpasang di mesinmu; ganti dengan font lokal proyekmu dan catat penggantiannya di catatan desain.
